# IronSplit

A race strategy platform for triathletes. Pick a goal, get split targets calibrated to your event, course, and the field.

Live at [ironsplit.com](https://ironsplit.com). iOS available on the App Store; Android in closed testing toward Play Store launch.

## Stack

- **Mobile**: .NET MAUI (iOS + Android)
- **API**: FastAPI (Python), PostgreSQL, deployed on Fly
- **Web**: Next.js + React, deployed on Vercel
- **Tooling**: Docker, GitHub Actions
- **Telemetry**: PostHog

## Status

This repo is the public landing page. Source for the mobile, API, and web tiers is private. Contact for demos, design discussion, or beta access.
